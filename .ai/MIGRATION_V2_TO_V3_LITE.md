# V2 → V3 Lite

V3 Lite does not replace the V2 protocol. It adds an automation layer under `.ai/orchestrator/`.

Preserved from V2: `task.yaml`, receipts, risk gates, state folders, ADRs, architecture authority and Git worktrees.

Added in V3 Lite: SQLite runtime coordination, leases/heartbeats, automatic Antigravity dispatch, GPT-5.6 review loop and human approval gates for high-risk tasks.

Use branch `v2` for the manual protocol-only baseline. Use `main` for V3 Lite.
