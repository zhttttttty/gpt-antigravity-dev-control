# ADR-005：日常单次委派与高级任务协议分层

状态：2026-10-28 按用户要求制定计划并实施。

## 决策

新增无需持久任务契约的 run 路径，复用现有 agy 参数探测和启动 Adapter。
它在干净 HEAD 的独立 Git 工作树实现，保留日志、实际变更和调用者指定的检查结果，
只交付待验收结果，不替代独立验收。高级 schema v2 生命周期继续存在。

轻量运行数据保存在 Git 公共元数据目录 agy-runs 下，避免普通项目为一次委派准备额外配置。
Git 工作树和结果默认保留，合并及清理均为后续明确操作。
本次不允许将脏源工作区悄悄丢弃；其未提交修改需先提交或另行处理。

原生子代理继承父会话权限。代理文件内的 sandbox_mode、approval_policy、model_provider、
mcp_servers 不能覆盖会话配置，因此移除这些权限假象，并在离线校验中指出无效字段。
“不修改文件”保留为角色指令，但不将其当作操作系统只读保证。
依据：[官方子代理配置说明](https://learn.chatgpt.com/docs/agent-configuration/subagents)。

## 验证与回滚

用临时 Git 仓库与伪执行器验证真正的工作树、检查命令、报告与失败路径，再运行原协议回归。
实际 agy、认证和费用未经真实调用不宣称已验证。
如需回滚，恢复本轮代码、配置模板、测试、文档与版本；保留已有运行目录和业务修改，
不能为了回滚删除执行工作树中的未提交成果。
