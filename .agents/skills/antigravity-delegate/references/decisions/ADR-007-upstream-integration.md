# ADR-007：上游高级协议与本地日常入口整合

状态：2026-10-28 按用户同意的对比结论实施。

## 决策

采用上游 main `db1426b` 的自适应路由、确定性 verify、分离预算、增量上下文和受控恢复。
在此源代码基线上保留本地 run、显式目标校验、安全配置安装、状态 JSON 和权限边界修正。
不将两个各自标为 3.4.0-local 的实现互相覆盖，整合后使用 3.5.0-local。

run 和 verify 共用进程执行与超时清理内核；默认按 argv 启动检查，shell 必须显式选择。
高级 verify 的契约审批、分阶段短路和工作区复核保留。run 的阶段与结果仍是轻量交接，
不冒充 QA/DONE，不增加七文件契约，也不以轻量入口绕过已有受控任务。

自定义原生代理仍继承父会话权限，不能以 sandbox_mode 等代理字段虚构独立隔离。
Root 选择 direct 后可明确派发有界原生 worker，不再把 direct 一概限定为 agy 故障回退。

上游 ADR-004（自适应委派）保留编号，本地此前未发布的安装决策 ADR-004 改号为 ADR-006，
保留其内容和日期；ADR-005 继续记录轻量入口。文档链接同步。

## 验证与回滚

保留两边现有测试，补充跨入口、argv/shell 选择与超时进程树处理验证，完成全量回归。
旧任务、回执、日志和工作树保持原字节。Git HEAD 不由本次文件整合命令重置，
后续发布须单独整理提交和历史，不把工作区版本号当作已发布版本。
