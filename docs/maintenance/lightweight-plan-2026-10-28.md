## 轻量入口约定

- `run "需求"` 默认针对干净仓库的已提交 HEAD 创建 `codex/agy-*` 分支和新工作树。
- 可选 --allow 限定相对路径模式，--check 指定检查命令；--dry-run 预览且不调用 Provider。
- 上下文、工作树、执行器报告、检查日志和最终 JSON 放到 Git 公共元数据目录的专用 agy-runs 子目录，
  无需创建或忽略业务项目的 `.ai/` 文件。
- 保护控制文件；允许范围与 Git 工作树是事后核验及 Git 隔离，不是操作系统沙箱。
- 执行器返回一份简短 JSON，不创建 QA/Review 文件。最终状态最多为 READY_FOR_REVIEW，验收由 Codex/用户完成。
- 检查命令由调用者显式输入并由控制器执行；绝不执行模型报告中的命令。未指定检查时如实标记 NOT_RUN。
- 不自动重试、提交、合并或删除结果工作树；失败保留日志和现场。
