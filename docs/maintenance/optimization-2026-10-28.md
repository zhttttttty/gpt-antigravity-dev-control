## 修复结果

| 原问题 | 当前行为 |
|---|---|
| init 的相对 --repo 被 chdir 后重复解析 | 先解析绝对路径；错误参数、空路径、不存在目标返回明确错误 |
| 显式子目录可能静默操作外层任务 | 任务命令要求显式目标等于 Git 根；默认从当前目录发现仓库的行为保留 |
| 只复制 `.codex/`，缺少规范配置 | 完整 profile 同时安装 `.ai/config.yaml`，外层实际安装后配置检查 PASS |
| 安装可能覆盖用户定制 | 整批冲突预检，默认拒绝不同内容；显式覆盖参数才允许替换，相同内容不重写 |
| 安装目标可能是链接或错误类型 | profile 拒绝符号链接、Windows 重解析点及文件/目录类型冲突 |
| 任务总览只能读文本或人工摘要 | 新增 `status --json`，实时输出状态、计数、进行中和全部未完成任务 |
| 配置缺失产生大量连带错误 | 先报告实际文件错误，避免 None/None 比较噪音 |

`PROJECT_STATE.yaml` 的空 active_tasks 在当前无 IN_PROGRESS 时不一定有误。
新总览只读任务目录，不据此重写人工摘要或宣告任务完成。

  确需覆盖时再加 `--overwrite-codex-profile`。既有项目文档和任务模板仍保留。
